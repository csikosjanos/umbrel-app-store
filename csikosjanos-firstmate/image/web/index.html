Firstmate Terminal Settings checking terminal… open terminal in its own tab
Values are write-only: after saving, they are never shown again or returned by the API. They are stored on the box in app-data/csikosjanos-firstmate/settings/ (mode 0600) and exported to every new shell in the terminal. Changes apply to new shells only: open a new tmux window (Ctrl-b c) or run source /settings/env.sh in an existing one. Agents that are already running keep the old values until restarted.

Secrets and API keys

For the harnesses (Claude Code, Pi, OpenCode) and for gh/git. Logging in interactively (claude, gh auth login, …) works too and persists.

Git identity

Exported as GIT_AUTHOR_* / GIT_COMMITTER_*. Leave empty to use git config instead.

Custom environment variables

Any other KEY=VALUE the harnesses or your tools need. Values are write-only as well.
